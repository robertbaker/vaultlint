`vaultlint` runs locally by default in both the CLI and the Web UI.

import { Badge, Card, CardContent, CardHeader } from "../../../ui";

## Local operations

Vault parsing, duplicate merging, password checks, URI syntax checks, batch editing, domain mapping, and password generation run on your machine or in your browser.

Encrypted exports (Bitwarden `encrypted: true`, Proton Pass `encrypted: true`, KeePass `.kdbx`, and Bramble `.bramble`) are rejected. To use a Bramble vault, open its password-protected KeePass export in KeePassXC and export it as CSV or XML.

Passwords are masked in CLI tables, activity logs, and JSON or Markdown reports. Plaintext vault data and AI API keys are not saved to `localStorage`.
