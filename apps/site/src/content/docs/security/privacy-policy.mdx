## Opt-In Network Requests

All network features are disabled by default and only run when you explicitly trigger them:

| Feature                                                      | Data Sent                                                                                                                                            | Destination                                                 |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **HIBP Breach Check**                                        | First 5 characters of a SHA-1 password hash (k-anonymity)                                                                                            | `api.pwnedpasswords.com`                                    |
| **AI Assistant / Categorization**                            | Item names and hostnames only (never item IDs, folder names, passwords, usernames, TOTP secrets, FIDO keys, or notes)                                | Your selected AI provider, or `127.0.0.1` when using Ollama |
| **Vendor CLI Import / Push** (`--from-cli`, `--push-to-cli`) | Nothing from `vaultlint`. It runs the vendor CLI you already installed and signed in to, which talks to that vendor's servers as it normally does    | The vendor's own servers                                    |
| **Redirect & Dead-Link Check**                               | HTTP `HEAD`/`GET` requests to each stored `http(s)` login URL, including its path and query; embedded `user:password@` credentials are removed first | Target login domains                                        |
| **Mobile App URI Validation**                                | App package/bundle IDs from `androidapp://` and `iosapp://` URIs                                                                                     | App store lookup endpoints                                  |
| **What's New Changelog**                                     | Standard `GET` request when checking release notes in the Web UI                                                                                     | `raw.githubusercontent.com`                                 |

## Hosted Site

If you access the hosted documentation or Web App on GitHub Pages, GitHub may collect standard HTTP request logs in accordance with the GitHub Privacy Statement. If you want zero third-party HTTP requests, run the CLI (`vaultlint`) or local Web UI (`vaultlint --ui`) offline.
