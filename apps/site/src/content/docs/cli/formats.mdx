Bramble’s `.bramble` backups and password-protected KeePass exports are encrypted, so vaultlint rejects them. To analyze a Bramble vault, export it as KeePass, open the `.kdbx` in KeePassXC, then export CSV or XML for vaultlint.

For exact provider fields, schema validation rules, and import/export limitations, see the [format schema reference](../format-schemas/).

## Cross-Format Conversion

Specify `--output-format` to convert between providers while auditing or deduplicating in a single pass. vaultlint infers only the unambiguous `.1pux` and `.xml` targets; `.json` and `.csv` outputs default to the input format, so set the target explicitly for those:

```bash
# Convert a Bitwarden JSON export to 1Password 1PUX after merging duplicates
vaultlint -i bitwarden.json -o migrated.1pux --auto-merge

# Convert a RoboForm CSV to Enpass JSON
vaultlint -i roboform.csv -o migrated.json --output-format enpass-json

# Convert an Enpass JSON export to Keeper JSON
vaultlint -i enpass.json -o keeper.json --output-format keeper-json

# Convert Keeper JSON to RoboForm CSV
vaultlint -i keeper.json -o roboform.csv --output-format roboform-csv
```

## Migration Coverage and Round-Trip Fidelity

All registered formats have import and export adapters, making the registered source-to-target pairs available through vaultlint's canonical schema. This describes adapter availability; it does not mean every provider field can be represented by every target.

Before export, vaultlint includes adapter-provided warnings for known limitations. The Web UI can compare those warnings across the supported target formats for the loaded vault. For a field-level check, `@vaultlint/vault-formats` exposes `inspectVaultRoundTrip(vault, format)`: it exports and parses the data in memory, then reports item counts and canonical field differences. The report contains field labels and counts, never field values. ZIP-based formats are inspected with the asynchronous parser.

The package also exposes `getFormatConformanceMatrix()` for registered import/export capabilities and `getFormatPairCoverage()` for the supported canonical-schema format pairs. Round-trip inspection is a runtime check for a particular vault; it does not replace adapter-specific fixtures or guarantee that a target password manager will accept every export.
