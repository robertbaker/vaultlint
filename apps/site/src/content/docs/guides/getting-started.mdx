## 1. Export Your Vault Safely

Export an **unencrypted** backup from your password manager or browser. vaultlint accepts Bitwarden, 1Password, KeePass, Proton Pass, Dashlane, LastPass, NordPass, Enpass, Keeper, RoboForm, Chrome-family browsers (Chrome, Edge, and Brave), Firefox, and Safari. See [supported formats](../../cli/formats/) for file types and [format schemas](../../cli/format-schemas/) for accepted fields.

Start the local Web UI on `http://127.0.0.1:4173`:

```bash
vaultlint --ui
```

Or run a dry-run audit directly in your terminal:

```bash
vaultlint -i vault.json --audit --dry-run
```

Prefer to build from source? See the [CLI Quick Start](../../cli/).
