### Target Modes

Use `--target-mode` in the CLI or the target mode selector in the Web UI to choose which values to edit:

| Mode        | Behavior                                                      |
| ----------- | ------------------------------------------------------------- |
| `all`       | Evaluate and apply replacement to all matching items          |
| `non-empty` | Only modify items where the target field already has a value  |
| `empty`     | Only populate items where the target field is currently empty |
| `clear`     | Clear the target field on matching items                      |

### CLI Examples

```bash
# Preview upgrading http:// URIs to https:// without writing changes
vaultlint -i vault.json --batch-edit --field uri --pattern "^http://" --replacement "https://" --dry-run

# Normalize item names (lowercase) and URIs (origin-only)
vaultlint -i vault.json -o vault-clean.json --normalize
```
