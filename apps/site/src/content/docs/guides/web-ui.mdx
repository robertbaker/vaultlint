The hosted Web App runs in your browser. You can also run the same interface locally with `vaultlint --ui`.

It accepts the same 20 file formats as the CLI for password manager and browser exports. See [supported formats](../../cli/formats/) for the list and [format schemas](../../cli/format-schemas/) for provider-specific columns and JSON fields.

## Loading a Vault

1. Open the [Web App](../../app/) or run `vaultlint --ui` locally and visit `http://127.0.0.1:4173`.
2. Choose or drop an unencrypted export, or click **Try the sample vault**. When running locally, the **Local CLI Bridge** can read Bitwarden, LastPass, Dashlane, Keeper, 1Password, Proton Pass, and NordPass CLIs after you sign in and unlock them. The hosted Web App cannot access CLIs installed on your device.

Each section opens with a heading that names it and summarizes what it does. The **Local-first workspace** note beside it is a reminder that nothing leaves your browser unless you start an opt-in network action.

## Undo, Redo & Export

Use **Undo** (`Ctrl+Z`) or **Redo** (`Ctrl+Y`) to review edits. Choose an export format in the header and click **Export** to download the updated vault.

Press `/` to jump to search in the Items section. Known export data-loss warnings appear before a download, and **Compare all supported export formats** shows what each format would keep or drop without exposing vault values.

## Keeping Work Across a Refresh

By default nothing is stored. You can opt in to an encrypted local recovery copy that expires after 8 hours without edits and can be removed at any time. See the [User Guide](https://github.com/robertbaker/vaultlint/blob/main/docs/USER_GUIDE.md#local-recovery-copy) for exactly what is kept and the limits of that protection.
