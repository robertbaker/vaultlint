## Opt-In HIBP Breach Check

`--check-compromised` (or **Check Breaches (HIBP)** in the Web UI) makes an optional request to the **Have I Been Pwned k-anonymity range API**. It sends the first 5 characters of each SHA-1 password hash; neither the plaintext password nor the full hash is sent.
