`vaultlint` includes optional AI folder categorization via `@vaultlint/ai`. **It is disabled by default** and never runs unless you explicitly enable it.

## What Gets Sent

When an AI action runs, `vaultlint` strips sensitive fields before sending the request:

## Supported Providers

| Provider ID  | Notes                                           |
| ------------ | ----------------------------------------------- |
| `openai`     | Default provider when `--enable-ai` is passed   |
| `anthropic`  | Claude models via Anthropic API                 |
| `openrouter` | Multi-model routing via OpenRouter              |
| `grok`       | xAI Grok models                                 |
| `gemini`     | Google Gemini models                            |
| `ollama`     | Local inference when Ollama runs on this device |

## CLI Usage

```bash
# Categorize folders using OpenAI (reads API key from environment or --ai-api-key)
vaultlint -i vault.json -o vault-categorized.json --enable-ai --ai-provider openai

# Run with a local Ollama server
vaultlint -i vault.json -o vault-categorized.json --enable-ai --ai-provider ollama --ai-model llama3.2 --ai-base-url http://127.0.0.1:11434
```
